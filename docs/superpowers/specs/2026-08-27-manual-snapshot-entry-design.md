# 手动快照入口精简设计

## 目标

降低全局顶栏的操作噪音，避免手动快照与完整备份混淆，同时保留在历史场景中记录特殊时点的能力。

## 范围

- 删除应用全局顶栏右上角的“保存快照”按钮。
- 历史快照页继续提供手动快照入口，按钮文案改为“记录当前时点”。
- 手动快照抽屉标题改为“记录当前时点”，提交按钮改为“确认记录”；提交期间显示“正在记录”。
- 保留 `/history?capture=manual` 深链接兼容性，外部或旧书签仍可直接打开记录抽屉。
- 备注字段及“行情过期或包含手动值时必须填写备注”的规则保持不变。
- 自动日终快照、再平衡前后快照、历史快照数据、后端接口和数据库结构均不修改。

## 交互设计

手动快照是历史复核功能，不再作为每个页面都可见的全局主操作。用户需要记录特殊时点时，进入“历史快照”页面并点击“记录当前时点”。抽屉继续展示备注输入框与现有规则说明；确认后创建 `manual` 类型快照并刷新历史列表。

全局顶栏保留“刷新”作为与实时市场数据直接相关的操作，不再同时展示语义相近但频率较低的“保存快照”。

## 错误处理

沿用现有结构化 API 错误展示与备注保留行为。提交失败时抽屉保持打开，用户输入的备注不丢失。

## 测试

- AppShell 不再渲染全局“保存快照”按钮，也不再从顶栏导航到手动快照深链接。
- 历史快照页显示“记录当前时点”。
- 抽屉标题为“记录当前时点”，提交按钮空闲时为“确认记录”、提交中为“正在记录”。
- `/history?capture=manual` 仍能打开同一抽屉，并从地址中消费该查询参数。
- 现有手动快照提交、错误保留和列表刷新测试继续通过。
