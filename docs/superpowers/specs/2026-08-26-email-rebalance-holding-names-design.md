# 邮件再平衡标的名称设计

## 目标

让投资组合日报中的再平衡建议无需额外查询即可识别纯数字或不熟悉的标的代码，同时移除当前价值较低的“原因”列。

## 范围

- 仅修改投资组合日报 HTML 中的“再平衡建议”表格。
- 标的显示格式为 `名称（代码）`。
- 当持仓名称与代码完全相同时，仅显示代码一次。
- 当邮件数据缺少代码对应的持仓名称，或同一代码对应多个不同名称时，回退为代码，邮件仍可正常发送。
- 表格保留“标的”“方向”“数量”“金额 (CNY)”四列，移除“原因”列。
- 网页端再平衡建议、再平衡 API、数据库结构和备份格式均不变。

## 设计

`build_digest_html()` 已同时接收组合分析结果与再平衡预览。组合分析中的每个持仓都包含 `symbol` 和用户维护的 `name`，因此邮件渲染器在生成表格前建立代码到名称的映射，不增加数据库查询，也不扩展再平衡响应结构。

对每条交易建议，渲染器按以下规则生成标的文本：

1. 找到名称且名称与代码不同：`名称（代码）`。
2. 找到名称但名称与代码相同：只显示代码。
3. 找不到名称：只显示代码。
4. 同一代码存在多个不同名称，无法可靠判断交易对应哪一个时：只显示代码。

最终文本继续经过现有 HTML 转义，避免名称或代码中的特殊字符破坏邮件结构。

## 错误处理

名称仅用于展示，不影响再平衡计算。映射缺失或存在歧义时采用代码回退，不因展示数据问题阻止日报发送，也不展示可能错误的名称。

## 测试

在邮件渲染单元测试中覆盖：

- 中文名称与纯数字代码显示为 `名称（代码）`。
- 名称与代码相同时不重复显示。
- 找不到名称时回退显示代码。
- 同一代码对应多个不同名称时回退显示代码。
- 名称和代码经过 HTML 转义。
- 再平衡表格不再包含“原因”表头或原因正文，同时仍保留方向、数量和金额。
